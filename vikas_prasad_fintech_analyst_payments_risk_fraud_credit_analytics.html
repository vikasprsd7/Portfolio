On-Chain AML & Transaction Monitoring (Synthetic Ledger)

SQL Python scikit-learn SHA-256 & Merkle Trees
  • Built a seeded synthetic ledger (43K transactions, 3,000 wallets, 125 illicit) with four AML typologies and legitimate look-alikes; 4 SQL red-flag rules flagged 40 of 41 designed target wallets with 3 false positives.
  • Engineered 27 wallet-level features (burstiness, pass-through speed, neighbour behaviour) and compared Logistic Regression, Decision Tree and Random Forest with SMOTE inside 5-fold CV; Random Forest reached 0.91 test ROC-AUC, catching 14 of 31 illicit wallets with 44 false alarms.
  • Built a SHA-256 hash chain with per-block Merkle roots (870 blocks): an altered transaction was detected at its block, and a re-mined block at the next link.
Model Limitation: Rules reach only 32% of illicit wallets (mules look ordinary), so graph methods are the next step.

Credit Card Fraud Detection Model

Python scikit-learn Keras SMOTE & GridSearchCV
  • Handled severe class imbalance (492 frauds in 284,807 Kaggle transactions, 0.17%) by comparing undersampling with SMOTE applied inside CV folds to prevent leakage; tuned Logistic Regression, KNN, SVC and Decision Tree with GridSearchCV (about 93% CV accuracy).
  • Evaluated a Keras network on an untouched test set: undersampling caught about 94% of frauds but wrongly flagged about 1,550 genuine transactions, while SMOTE gave about 83% precision with only 15 false alarms.
Model Limitations: Anonymised PCA features, single split, fixed 0.5 threshold, only 98 test frauds.
